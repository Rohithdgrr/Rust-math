# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please email `security@mathverse.dev` with:
- Description of the vulnerability
- Steps to reproduce
- Impact assessment

Expected response times:
- 24 hours: acknowledgment
- 7 days: initial assessment
- 30 days: fix target

We do not currently offer a bug bounty, but we credit reporters in release notes.
